# QIF v0.8.20

QIF v0.8.20 adds Recovery Evidence Challenge and Adversarial Validation.

## Highlights

- Controlled challenge protocols for source loss, evidence tamper,
  contradiction, common-cause failure, and multi-session evasion.
- Reproducible run outcomes, observations, exposed failure domains, and
  challenge-adjusted recovery-independence grades.
- Fail-closed governance for incomplete, unverified, exposed, or evaded
  challenge results.
- 135 retained Skill supply-chain fixtures within a 1,723-rule negative corpus.

## Boundary

Passing local verification proves structural consistency, not challenge
representativeness, adversarial robustness, actual monitor coverage, real-world
defense, attacker capability, safety improvement, or recovery authority.
