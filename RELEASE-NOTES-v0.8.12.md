# QIF v0.8.12: Agent Skill Distribution

QIF can now be installed as a standard Agent Skill. Compatible AI systems can
discover when QIF applies, follow its evidence and governance discipline, and
use the bundled canonical verifier without requiring the full repository.

Highlights:

- standards-conformant `SKILL.md` with progressive disclosure;
- guided discovery, evaluation, world-model, expert-judgment, and authoring modes;
- deterministic versioned directory and zip distributions;
- bundled canonical QIF CLI, schemas, examples, and selected documentation;
- source, integrity, platform-limit, mutation, and end-to-end verification;
- release assets for both Agent Skill and document-oriented portable packages.

The Skill is a procedural capability, not an autonomous decision maker. It
does not establish semantic truth, approve a verdict, execute changes, or
grant organizational authority.
