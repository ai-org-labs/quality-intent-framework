# QIF v0.8.2

QIF v0.8.2 adds **Local Applicability and Reproduction** to the Living QIF
Ledger.

Portable quality knowledge now has to earn local eligibility. For every tested
Decision Pattern or Quality Intent, QIF records:

- the named local Evaluation Target;
- matches and mismatches across seven applicability dimensions;
- source cases and genuinely separate unseen cases;
- expected and observed decisions;
- reproducible agreement;
- recorded evaluator identity separation;
- an outcome for every preserved counterexample;
- local evidence status and source trust;
- deterministic sufficiency and governed-activation eligibility.

Eligibility is deliberately narrow. It permits an accountable governance
review; it does not activate knowledge, approve a decision, grant authority, or
prove semantic truth.

The committed example demonstrates successful case-level reproduction but
remains `not-eligible` because both source trust and local evidence are
example-only. This prevents repository examples from promoting themselves into
operational truth.

Verification includes 16 positive package checks and 1,354 retained negative
fixtures across the full QIF suite, including 23 new local-validation cases.

Release assets include the current vendor-neutral QIF portable package and its
SHA-256 checksum.
