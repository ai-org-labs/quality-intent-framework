# QIF v0.4.10

QIF v0.4.10 extends retained runtime verifier coverage to the `evaluation-target` package surface.

## Added

- `tools/fixtures/evaluation-target-cases.mjs` as the source of truth for invalid evaluation-target packages.
- `tests/fixtures/evaluation-target/` committed corpus generated by `npm run build-fixtures`.
- Evaluation-target positive package execution in `tools/run-fixture-tests.mjs`.

## Changed

- Runtime verifier now explicitly checks evaluation target id uniqueness.
- Runtime verifier now rejects unsupported evaluation target domains.
- Standing fixture suite now covers 6 positive packages and 309 retained negative fixtures.

## Verification

- `npm test`
- `node tools/validate-qif-runtime.mjs assessments/qif-self-evaluation-v0.4.10.json`
- AOF v11.4.0 `situation-assess`
- AOF v11.4.0 `organization-verify`
- AOF v11.4.0 `command-routing-audit`
- AOF v11.4.0 `review-provenance-audit`

## Boundary

Verifier success proves structural integrity, traceability, reference resolution, confidence reproducibility, and covered rule compliance. It does not prove semantic quality truth. The remaining v0.4.x retained fixture frontier is the `review-run` runtime package surface.
